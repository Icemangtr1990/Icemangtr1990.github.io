Proyecto Final DAW · 2026

FitMealApp

Aplicación web completa para la planificación de comidas y la generación automática de listas de compras, con acceso por roles y administración de usuarios y recetas.

Funcionalidades

  • Autenticación con roles usuario y admin (Spring Security).
  • Alta de recetas con ingredientes y cantidades añadidos dinámicamente.
  • Planificador que asigna recetas a usuarios y fechas, con consulta por usuario.
  • Lista de la compra generada a partir de las recetas planificadas.
  • Panel de administración para crear y eliminar usuarios y recetas.

Decisiones técnicas

  • Arquitectura MVC con Thymeleaf y empaquetado WAR para Tomcat.
  • Consultas parametrizadas con PreparedStatement para evitar inyección SQL.
  • Ingredientes modelados como JSON y procesados con Jackson.
  • Consulta agregada con GROUP_CONCAT para mostrar los usuarios de cada receta.
  • Integridad referencial con claves foráneas y ON DELETE CASCADE.
