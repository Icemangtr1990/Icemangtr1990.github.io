FitMealApp

Aplicación web completa para la planificación de comidas y la generación automática de listas de compras, con acceso por roles y administración de usuarios y recetas.

Funcionalidades

  • Autenticación con roles usuario y admin, contraseñas BCrypt y login contra base de datos.
  • Gestión de recetas con ingredientes en JSON y panel de administración de usuarios.
  • Planificador que asigna recetas a usuarios y fechas (solo administradores).
  • Lista de la compra con ingredientes agrupados, filtro por fechas y versión imprimible.
  • API REST con DTOs, paginación y documentación Swagger/OpenAPI.
  • Interfaz responsive con validación, mensajes de confirmación y estados vacíos.

Decisiones técnicas

  • Arquitectura por capas: entidades JPA → repositorios Spring Data → servicios → controladores.
  • HikariCP como pool de conexiones y Flyway para migraciones versionadas.
  • Seguridad con BCrypt, CSRF, control por roles y Bean Validation; errores JSON en la API.
  • 17 tests con JUnit 5, H2 y MockMvc, cobertura JaCoCo e integración continua con GitHub Actions.
  • Docker Compose para levantar la aplicación y MariaDB con un solo comando.
  • Frontend Thymeleaf con fragments compartidos y sistema de diseño propio.
